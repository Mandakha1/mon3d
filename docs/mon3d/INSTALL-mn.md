# Mon3D 2026 — суулгах заавар

Mon3D бол SolidWorks, Fusion-тай төстэй, үнэгүй, нээлттэй эхийн параметрт 3D CAD програм.
Монгол болон англи интерфейстэй. Гараар загварчилж болно, эсвэл Claude / ChatGPT-ээр удирдуулж
загварчлуулж болно. [SolidCraft](https://github.com/tangency-labs/solidcraft) дээр суурилсан.

## Windows (10, 11 — 64 бит)

1. `mon3d-2026-<хувилбар>-windows-x64-setup.exe` файлыг татна.
2. Давхар товшоод суулгана. Администраторын эрх шаардлагагүй (`%LOCALAPPDATA%\Programs\Mon3D`).
   - Windows «SmartScreen» анхааруулга гарвал **More info → Run anyway** дарна (програм одоогоор
     кодын гарын үсэггүй).
3. Start цэс → **Mon3D 2026**.

Чимээгүй суулгах: `…-setup.exe /S` (ширээний товчлолтой бол `/DESKTOP=1`).
Устгах: **Settings → Apps → Mon3D 2026 → Uninstall**. Таны төслүүд болон тохиргоо устахгүй.

Дараа жилийн **Mon3D 2027**-г суулгахад өмнөх хувилбарын оронд суух бөгөөд тохиргоо,
автомат хадгалалт хэвээр үлдэнэ.

### Шаардлага

- Windows 10/11, 64 бит
- DirectX 12 эсвэл Vulkan дэмждэг видео карт

## Хэл солих

**Preferences → General → Language → Монгол** (эсвэл English). Windows-ийн хэл Монгол бол
Mon3D анхнаасаа Монгол хэлээр нээгдэнэ.

## Файлын формат

- **.sc** — Mon3D/SolidCraft-ийн төслийн файл (SolidCraft-тай бүрэн нийцтэй).
- **STEP, IGES** — бусад CAD програмтай (SolidWorks, Fusion, Kompas, FreeCAD) солилцох.
- **STL, 3MF, OBJ, glTF** — 3D хэвлэл, дүрслэл.

## Мэдээ, сургалт

Mon3D нээгдэхэд шинэ мэдээ, сургалт, санал байвал баруун доод буланд карт гарна (Windows дээр
мэдэгдэл бас ирнэ). **Тусламж (?) → Мэдээ, сургалт…** цэснээс бүгдийг харж, унтрааж болно. Програм
зөвхөн мэдээний файлыг татна; таны тухай ямар ч мэдээлэл илгээхгүй.
